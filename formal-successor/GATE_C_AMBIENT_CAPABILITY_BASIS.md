# Gate C Ambient Capability Basis

## Result

**Partial.** The branch now has exact, kernel-checked interfaces for the four normalized candidate
capabilities and a finite theorem showing interface-level independence. This does not prove that
the bundle is sufficient to regenerate the protected predecessor, nor that each interface is
semantically minimal at the declared horizon. `IC-THM-C-000` therefore remains `PLANNED`.

## Relation under inquiry

The current successor position names `CtxFam + RegPred + Ind+ + BindingPresentation` as a
capability basis up to definitional equivalence. Its formal meaning is now:

- `CtxFam` supplies contexts, substitutions, indexed types and terms, functorial reindexing, and
  comprehension data and laws.
- `RegPred(CtxFam)` supplies a proof-insensitive regular predicate doctrine: entailment, top,
  finite meet, equality, existential reindexing, Beck–Chevalley, and Frobenius.
- `IndPlus(CtxFam)` supplies substitution-stable initial algebras only for admitted positive
  indexed operators.
- `BindingPresentation(CtxFam, RegPred)` supplies `TyCode`, `El`, contextual atomic relations,
  declared stronger logical operators and their laws, and a contextual theory. Atomic denotations,
  logical extensions, and theory sequents live in the ambient predicate fibres. This is
  binding-supplied content, not content manufactured by the regular core.

The proposed stronger relation is a total, coverage-indexed regeneration map from those
capabilities to every protected v2.0 capability, together with semantic ablation models proving
that removing each retained capability destroys at least one exact protected target.

The question making that relation the answer is: **which smallest typed ambient capability basis
regenerates every protected predecessor distinction, and which exact protected construction fails
when each candidate capability is removed?**

## Derivation and breakers

The bounded local candidate correctly separated context substitution from regular predication but
gave neither exact types nor a regeneration map. Its attempted dependency was circular: deriving
`CtxFam` while assuming categorical contexts and substitution. It also placed existential
reindexing under positive generation. Those claims were not accepted.

The checked module instead makes every dependency explicit. Its Boolean information model gives,
for every candidate capability, two profiles with the same view of all remaining capabilities and
different values at the removed capability. No function of that remaining view can recover the
removed coordinate. This is a decisive breaker for information-level derivability by projection;
it is not yet a semantic ablation minimality theorem.

The regeneration attempt also broke the first standalone `BindingPresentation`: its host-level
`Prop` interpretations had no typed relation to `CtxFam` or `RegPred`, so it could not witness the
claimed presentation “over the ambient.” The retained form is now indexed by both interfaces and
interprets atomic relations, logical extensions, and theory sequents in explicit contexts. Partial binding and
open-port completion remain later derived constructions; they are not packed into this ambient
presentation.

Four stronger breakers remain required:

1. remove context-indexed substitution and show an exact protected contextual question or
   continuation transport cannot regenerate;
2. remove regular predicate structure and show an exact protected relational construction fails;
3. remove positive indexed generation and show an exact protected recursive source or evidence
   family fails;
4. remove binding presentation and show an exact protected domain relation, logic, or theory
   interpretation fails.

Each breaker must also attempt a derivation from the surviving interfaces. Failure to find a
derivation leaves `Unknown`; it does not establish independence.

## Non-collapse and propagation

The module records, rather than erases, these boundaries:

- capability basis is not a preferred constructor list;
- semantic existence is not syntactic representability;
- regular predication is not binding-supplied nonregular content;
- evidence representation is not evidence activation;
- an interface-level independence theorem is not protected predecessor regeneration;
- a finite ablation is not semantic ablation minimality;
- typed setup is not a Gate C pass and gives no runtime or Rust authority.

The attempted total regeneration exposed the next exact missing relation: semantic minimality must
quantify over uniform generation of protected composites after arbitrary conservative extension by
fresh binding atoms. Expressivity alone is vacuous because every desired composite could be added
as an atom. The next live position therefore types that `UniformGeneration` boundary and its target
correspondence before returning to the total regeneration map. It is not a dependent completion,
observation, determination, or factorization theorem.
