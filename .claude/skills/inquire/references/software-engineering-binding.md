Status: **DERIVED**. This document renders the canonical question algebra for software work. It
introduces no semantic primitive, authority, runtime opcode, or second workflow language.

Semantic authority remains
Inquiry_Calculus_v2_0.tex. The root AGENTS.md is the active

## Engineering frame

Before selecting a change, reconstruct the smallest frame that can preserve the protected
difference:

    frame
        the boundary inside which the requirement and actual behavior are compared

    possible occupants
        every typed implementation, state, return, or explanation still admitted

    actual occupants
        values or occurrences established by fresh repository/tool/runtime probes

    arrangement
        ownership, containment, dependency, interface, data-flow, event, and version relations

    relational paths
        the exact routes through which an occupant can affect a protected consumer

    protected consequence
        the behavior, authority, replay property, safety property, or acceptance criterion at risk

File, symbol, lexical, and temporal proximity generate candidate loci. They do not establish
responsibility. A locus is admitted only when a typed forward path connects it to the protected
observable, or when an actual separator discriminates it from rivals.

question, and first-order IProg.

## Availability and succession

A question occurrence is indexed by the checked source Ask, its continuation identity, explicit
environment, and provenance. The same semantic question and supported answer under two different
continuations may have different lawful successors.

A live engineering question must be:

    formable
    and applicable
    and executable when execution is required
    and (productive or required by an explicit discharge obligation)

Productivity means that supported answer classes can lead to protected-different continuations.
Required discharge retains an obligatory Probe, Check, Warrant, exact support, or reconstruction
question even when two discretionary branches are not yet supported.

Surface wording, route annotations, and clock positions are erasable explanations. The answer
selected through the declared mode controls the stored first-order continuation.

## Evidence boundary

    Pure       propagates admitted structure
    Generate   expands a candidate field
    Probe      creates a new actual return
    Check      discriminates the return against a declared claim
    Warrant    accepts a checked change under the governing authority

Preserve:

- raw return before interpretation;
- exact occurrence, tool/provider, input, version, environment, and command;
- mixed-mode and partial-answer provenance;
- Unknown components;
- the checker and its declared coverage;
- the accepted decision and reopen condition, when acceptance occurs.

Never preserve private chain-of-thought or sensitive raw content merely to make provenance verbose.
A safe digest/reference and a concise supported conclusion are sufficient when disclosure would
violate privacy or security.

## Positive challenge

Rejecting a requirement, hypothesis, patch, or design needs a positive separator:

    standing presentation
    candidate
    typed relation placing them in incompatible protected cells
    relevance to the current determination
    non-circular support

Failed search, failed equality, failed retrieval, projection, and unstructured disagreement remain
Unknown.

For reciprocal challenge, retain the admitted oriented use, positive departure, exterior, entire
same-use reverse fiber, protected recovery, supported seed, independently admitted second
orientation, both residuals, and downstream-only compatibility. A generic converse is not
same-use reciprocal return.

## Search, localization, and representation gaps

Use the return fiber after a candidate succeeds:

> What other candidates would have produced the same observed return?

What is constant over that entire field is what the evidence established. If protected-different
causes survive, construct a separator.

Distinguish:

- **materialization gap** — the admitted language can state the discriminator, but it has not yet
  been found or executed;
- **expressibility gap** — no admitted observation can state a witnessed protected difference.

The first continues bounded search. The second opens a representation, probe, or binding extension.
Tool construction is justified only by the pair it newly separates.

## Development state as a sufficient present

A useful current development presentation is a fold of repository history, not a replacement
history. Four obligations remain distinct:

1. **Consequence sufficiency** — current protected consumers factor through the presentation.
2. **Recursive updatability** — the presentation can lawfully incorporate a new event or return
   without silently rewriting prior evidence.
3. **Regenerative recoverability** — removed detail can be reconstructed, reacquired, or reopened
   when its distinction becomes protected.
4. **Bounded active size** — active context remains within a resource bound.

None implies another. Exact recoverability is also distinct from cheap recoverability: a
reconstruction may exist while exceeding the declared latency, token, storage, or tool budget.

When extending a present, preserve prior presentation and protected-observation rows exactly unless
a separately warranted revision authorizes change. A newly protected continuation that separates a
folded pair returns a positive reopening witness.

## Abstraction and method learning

Structure earns retention only through protected behavior, authority, provenance, recovery, or
bounded reacquisition:

    refine where consequences split
    fold where they do not
    retain the smallest cue that still regenerates the protected distinction

A recurrent engineering route may become a transparent method only if its expansion, applicability,
failure exits, provenance, and reopening behavior regenerate. Frequency proposes; it does not
warrant. Method names are provenance, not dispatch policy.

After apparent success, ablate each candidate-owned component in a reversible trial. Retain it only
when a discriminator witnesses necessity.

## Recurrence and stops

Fingerprint question occurrence, continuation, bindings, live Frontier, repository actuality,
horizon, and coverage. Same state plus same answer is no progress. Recur only across a new actual
return, admitted distinction, representation/binding change, authority change, observed state
change, or strictly smaller finite frontier.

Use only:

    Satisfied | Equivalent | Impossible | Blocked | Unknown | ResourceBounded

Equivalent closes one branch. Impossible needs a certificate. Blocked names the unavailable
capability. ResourceBounded returns a partial result and remaining frontier. Only Satisfied
closes the task.
